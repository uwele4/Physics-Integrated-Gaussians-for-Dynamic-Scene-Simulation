# Physics-Integrated-Gaussians-for-Dynamic-Scene-Simulation

In this Repository we use the pipeline from the paper [PhysGaussian](https://github.com/XPandora/PhysGaussian) to create our own customized dynamic 3D Gaussian splatting scenes.
The central part of this project is to build the config files.
Here is a link to our trained [models](https://example.com)
The train.py, and convert.py file form [3D Gaussian Splatting](https://github.com/graphdeco-inria/gaussian-splatting/tree/d9fad7b3450bf4bd29316315032d57157e23a515) were used and adapted to our COLMAP version. This repository is included as a submodule to PhysGaussian.
