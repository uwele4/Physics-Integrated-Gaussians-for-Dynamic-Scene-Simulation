# Physics-Integrated-Gaussians-for-Dynamic-Scene-Simulation

In this Repository we use the pipeline from the paper [PhysGaussian](https://github.com/XPandora/PhysGaussian) to create our own customized dynamic 3D Gaussian splatting scenes.
The central part of this project is to build the config files.
